무엇을 도와드릴까요?

설정하다 막히시면 아래를 먼저 봐 주세요. 찾는 내용이 없으면 메일 주시면 됩니다. 직접 읽고 답장드립니다.

처음 설정하기

  1. 권한 세 가지를 허용해 주세요 알림 · 실시간 현황 · 스크린 타임. 특히 스크린 타임 권한이 없으면 퀴즈가 뜨지 않아요.
  2. 예외로 둘 앱을 고르세요 (선택) 시간이 되면 휴대폰 전체가 잠깁니다. 전화처럼 늘 열어둘 앱이 있으면 설정 › 항상 쓸 수 있게 둘 앱 에서 빼 두세요.
  3. 홈에서 시작하기를 누르세요 이때부터 시간을 셉니다. 시간이 되면 쓰던 화면 위로 잠금이 올라오고, 「퀴즈 풀러 가기」를 누르면 퀴즈가 나와요.

자주 묻는 질문

잠금 번호를 잊어버렸어요

번호를 넣는 화면에서 「번호를 잊으셨나요?」를 누르면 두 자리 곱셈 문제가 나옵니다. 맞히면 번호를 새로 정할 수 있어요.

아이가 답을 외워 버리지 않도록 매번 다른 문제가 나옵니다. 계정이 없는 앱이라 메일로 번호를 찾아드릴 수는 없어요.

시간이 지났는데 퀴즈가 안 떠요

세 가지를 차례로 확인해 주세요.

1. 스크린 타임 권한 — 설정 › 권한 에서 「허용됨」인지 봅니다. 아이폰 설정 › 스크린 타임에서 꺼져 있어도 동작하지 않아요.

2. 지켜보기가 켜져 있는지 — 홈에서 「시작하기」를 눌러야 시간을 세기 시작합니다.

3. 작동 시간대 — 설정 › 언제까지 가 지금 시각을 포함하는지 봅니다. 기본값은 오전 8시–오후 8시예요.

퀴즈가 너무 자주 나와요 / 너무 뜸해요

설정 › 나오는 주기 에서 3분·5분·10분·15분 중에 고르시면 됩니다.

한 관문에 낼 문제 수도 1~3개로 바꿀 수 있어요. 처음에는 짧은 주기 + 한 문제로 시작해서 아이가 익숙해지면 늘리시는 편이 편합니다.

아이가 문제를 어려워해요

설정 › 아이 에서 나이를 한 단계 낮춰 주세요. 만 3–4세 문제는 글자를 몰라도 그림과 숫자만으로 풀 수 있게 만들었습니다.

설정 › 문제 종류 에서 아직 이른 영역(예: 영어)을 꺼 두셔도 됩니다.

오답에는 벌이 없어요. 다시 고르면 되고, 두 번 틀리면 정답이 은은하게 빛납니다.

별은 무엇이고, 건너뛰기는 어떻게 하나요?

퀴즈를 통과하면 별이 쌓입니다. 모은 별을 써서 퀴즈를 한 번 건너뛸 수 있어요.

건너뛰기에 드는 별은 설정 › 별로 건너뛰기 에서 정합니다. 「사용 안 함」을 고르면 건너뛰기 자체가 사라집니다.

아이가 앱을 지우거나 꺼 버리면요?

지켜보기를 끄려면 잠금 번호가 필요합니다. 번호를 모르면 끌 수 없어요.

앱 자체를 지우는 것까지는 막지 못합니다. 아이폰 설정 › 스크린 타임 › 콘텐츠 및 개인 정보 보호 제한 › 앱 삭제 허용 안 함을 함께 켜 두시면 지우지 못하게 할 수 있어요.

아이 기록은 어디에 저장되나요?

휴대폰 안에만 저장됩니다. 현재 버전은 계정도 서버도 쓰지 않습니다.

잠글 앱을 고를 때도 앱은 어떤 앱을 고르셨는지 알지 못합니다. 애플이 건네주는 식별 불가능한 표식만 다루기 때문이에요.

기기를 바꾸면 기록이 옮겨지나요?

아니요. 계정이 없어서 기기 사이로 옮겨지지 않습니다. 새 기기에서는 처음부터 설정하시면 됩니다.
