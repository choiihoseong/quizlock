01수집하지 않는 것

아래 항목을 수집하지 않습니다.

  • 이름·생년월일·연락처·이메일 등 신원을 알 수 있는 정보
  • 위치, 연락처, 사진, 통화·문자 기록
  • 광고 식별자, 기기 고유 식별자
  • 아이가 사용한 앱의 내용·화면·입력
부모가 설정에서 넣는 아이 이름은 별명으로 충분합니다. 퀴즈에서 아이를 부르는 데만 쓰이고, 이 값 역시 휴대폰을 벗어나지 않습니다.

02휴대폰 안에만 저장되는 것

앱이 동작하려면 아래 값이 필요합니다. 모두 기기 내부 저장소에만 있으며 어떤 형태로도 외부에 전송되지 않습니다.

저장 항목쓰이는 곳
아이 별명, 나이대문제의 난이도와 부르는 말을 정하는 데
문제 종류 선택어떤 퀴즈를 낼지
퀴즈 주기, 작동 시간대언제 관문을 열지
보호자 잠금 번호아이가 지켜보기를 끄지 못하게
오늘 푼 문제와 정답 여부보호자에게 보여 주는 기록
모은 별과 사용한 별보상과 관문 건너뛰기
잠글 앱 목록시간이 됐을 때 무엇을 잠글지
보관 기간이 따로 없습니다. 앱을 삭제하면 위 값이 모두 즉시 사라집니다. 별도의 파기 요청 절차가 필요 없는 구조입니다.

03권한을 요구하는 이유

퀴즈락은 정해진 시간에 끼어드는 앱이라 몇 가지 권한이 필요합니다. 각 권한이 왜 필요한지, 무엇에 쓰이지 않는지까지 밝힙니다.

안드로이드

  • 다른 앱 위에 표시 — 시간이 됐을 때 아이가 쓰던 화면 위로 퀴즈를 띄웁니다. 퀴즈를 풀면 즉시 사라집니다. 광고 표시나 화면 내용 수집에는 쓰지 않습니다.
  • 알림 — 남은 시간을 화면 맨 위에 계속 보여 줍니다.
  • 배터리 최적화 제외 — 이것이 없으면 타이머가 중간에 멈춥니다.
  • 사용 정보 접근 (선택) — 보호자 기록의 ‘오늘 사용 시간’을 채우는 데만 씁니다. 집계는 전적으로 기기 안에서 이루어지며 전송하지 않습니다. 허용하지 않아도 모든 핵심 기능이 정상 동작합니다.

iOS

  • 알림 · 실시간 현황 — 남은 시간을 잠금화면과 다이내믹 아일랜드에 보여 줍니다.
  • 스크린 타임 (Family Controls) — 시간이 됐을 때 앱을 잠급니다. iOS는 프라이버시 보호를 위해 어떤 앱을 골랐는지 앱에게 알려주지 않으며, 저희도 알 수 없습니다.

04제3자 제공 · 광고 · 분석

현재 버전에는 없습니다. 광고 SDK, 분석 SDK, 크래시 리포팅을 포함해 어떤 제3자 라이브러리도 넣지 않았습니다. 수집하는 정보가 없으므로 판매하거나 공유할 데이터 자체가 없습니다.

앱은 실행에 필요한 글꼴을 앱 안에 함께 담고 있어 평소 동작에 외부 통신이 발생하지 않습니다.

뒤에 광고나 결제처럼 외부와 통신하는 기능이 들어가면 이 문서를 먼저 고치고 앱 안에서도 알린 뒤 적용합니다. 그때 어떤 정보가 어디로 가는지 이 자리에 적겠습니다.

05아동의 개인정보

퀴즈락은 보호자가 설정하고 아이가 사용하는 앱입니다. 아동에게서 개인정보를 수집하지 않습니다. 현재 버전에서 아이가 접하는 화면에는 계정 가입·로그인·결제·외부 링크·채팅·광고가 없습니다.

보호자 설정 화면은 잠금 번호로 보호되며, 지켜보기를 끄려면 그 번호가 필요합니다.

06이용자의 권리

수집하는 정보가 없으므로 열람·정정·삭제를 요청할 대상도 없습니다. 기기에 저장된 값은 언제든 보호자가 직접 다룰 수 있습니다.

  • 수정 — 부모 설정에서 모든 값을 바꿀 수 있습니다.
  • 삭제 — 앱을 삭제하면 저장된 모든 값이 즉시 사라집니다.
